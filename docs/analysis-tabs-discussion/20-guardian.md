## 3. 案を評価する Yes/No チェックリスト（18 項目）

## 4. 本人に確認すべき論点（今回の依頼と過去の決定が衝突しうる点）

どちらが優先かはここでは決めない。依存の順に並べた（前の答えで後の前提が変わる）。

1. **「タブ」はどこのタブか**
   - 現状: 分析はトレーニングタブ右上から push する 1 枚の画面（J6・9/30）
   - 解釈 a: 分析画面の中の切替（上部の「強さ｜継続｜中身」）→ J6 と衝突しない
   - 解釈 b: 画面下のタブ（4 つ目「分析」、またはトレーニングタブの中を上下で分ける）→ J6「タブを増やさない」と INV-7 の判断を覆す
   - 記録には本人が b を意図したという事実はない。memory `feedback_confirm_user_option_definition` に従い、評価の前に 1 問で確かめる
2. **最初に開くタブと、前回のタブを覚えるか**
   - 「強さは上の方」（10/7、強い意志はない）と、C-8「推移に 2 タップ以内」は、既定タブ次第で両立しない（強さを既定にすると推移は 3 タップ）
   - 本人の「上の方」は 1 枚の縦並びが前提の発言なので、分割後にそのまま「既定タブ = 強さ」と読み替えてよいかは未確認
3. **タブを移ったとき、期間は保つか戻すか**
   - 10/10 の原則は「期間ナビで中身を替える」までで、タブ間の期間の扱いは記録にない
4. **心肺と体重の行の置き場**（強さのタブに残すか）
   - 10/7 の決定は「強さと同じ期間」「強さブロックの先頭」。分割で「中身」に見えるものを移したくなる点が衝突する
5. **「中身」の範囲**: 総ボリューム・曜日×部位・本番セット数・種目ごとの推移を 1 タブにまとめるか。推移一覧は週ナビの影響を受けない（全期間の種目一覧）ので、週ナビの下に置くと「週で絞れる」と誤解されうる【推測】

- 【推測】画面内の「強さ｜継続｜中身」切替は、見せ方も期間の単位も違う 3 つを分けるので、G-1（期間だけ違うものはタブにしない）とは矛盾しない。brief の整理と同じ
- 【推測】破りやすいのは G-1 そのものより、**B-2（期間の統一）・B-4（タブ間の期間の扱い）・B-5（推移が 3 タップ）・B-1（二重セグメント）**の 4 つ。案の比較はこの 4 点の扱いで差が出る
- 下タブ化（解釈 b）は J6 の再審になるので、本人の明示なしに推奨案に入れない
