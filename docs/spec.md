## 作り直しの経緯

2026-04-25 v1 (Plan A) を廃止し v2 として作り直し決定。**初期構想 (朝の習慣化ツール) と現構想 (1 日サイクル設計) のズレが連続発生**し、設計変更のたびに影響範囲が膨張したため、ドメイン / データモデルから書き直す判断。

drift の真因は「初期構想の解像度不足」で、朝の習慣は朝単体では成立せず夜→朝の全結合循環を言語化できていれば防げた。詳細経緯・drift 真因診断は memory `project_life_tracker_v2_core.md` 参照。

v2 ではコアの解像度を上げてから実装に入る。スコープ判定基準 (後述) で新機能採否を機械的に判定する。

## v2 確定コア定義

> **Life Tracker v2 = 1 日サイクル (朝・昼・夜の全結合チェーン) を設計・記録・可視化する個人ツール**

### スコープ判定基準

**1 日サイクル (行動・身体状態) に直接影響する要素のみ扱う**

新機能追加時、必ず本基準に照らす。スケジュール / 健康への影響が薄ければ却下。

### 対象

- 習慣化 (デフォルトパターンとして内包)
- 1 日のスケジュール (予実分離)
- 健康記録 (睡眠 / 食事 / 運動 / 体調)
  - ※ 本スコープ基準は「何を扱うか」しか判定しない。**どの解像度で扱うか**は別途判断が要る (v16 のトレーニング詳細化はこの穴を通った例)
- **学習記録** (PMBOK 計画と統合可能)

## 構造原則

### 原則 1: 1 日 = 全結合の影響グラフ

- フェーズ間は線形チェーンではなく全方向に影響
  - 朝の起床時刻 → 夜の就寝時刻 (飛び越し影響)
  - 昼の疲労度 → 夜の行動の質
- 時間帯 (朝 / 昼 / 夜) は **第一義的な区切りではない**。表示・分析時のフィルタ

### 原則 2: タスクと時刻枠を分離

- v1 (Plan A) では blocks 内に内容が直接埋まっており、タスク移動が扱えなかった
- v2 では「タスク (やりたいこと)」と「時刻枠」を別エンティティに
- タスクは時間帯間を移動可能 (朝できなければ昼 / 夜に振り替え)

### 原則 3: デフォルトパターン中心

- 「いつもの 1 日」をデフォルトパターンとして定義
- 当日の予定はパターン適用 + 当日修正で生成
- 当日の実績との予実差分で習慣化フィードバック

---

## v1 との断絶ポイント

- v1: blocks 内に予定・実績・内容が混在 → タスク移動・並列が扱えなかった
- v2: scheduled_task / actual_task 独立 + 並列許容 + サブ入力分離 + 種別正規化 → drift 耐性を構造で担保
- v2: 予実は DB レベル完全独立 (FK なし)、UI / Service 層で結合 (詳細は `domain-model.md` データモデル原則「予実紐付けなし」)

  - **トレーニング進捗の可視化** (PR / 推定1RM / ボリューム推移 / 部位別バランス / 連続週数)
  - ~~未来日表示は **Phase 1 範囲外**~~ → **2026-09-30 本人決定で前倒し**: 予定タブの週帯で過去・未来の日へ移れる。過去日は予定を編集できない（実績入力だけ可）。繰り返しの予定は世代管理（`day-cycle-walkthrough.md`）
  - **時刻のないやること・目標の回数**（2026-10-13〜14 本人決定、2026-10-14 実装・本番未適用。仕様 `untimed-tasks-design.md`、規則のまとめ `day-cycle-walkthrough.md`「時刻のないやること」）
    - 予定タブの時刻つきの一覧の下に「やること」の節（時刻なしが 1 件も無い日は出さない）。行 = 名前・2 行目（種類・繰り越し中は「10/10 から」・「この日だけ変更」）・右端の丸（目標 1 はチェックの丸、2 以上は「3/8」の丸。枠は回数 / 目標の長さだけ塗る進捗の輪で、区切らない）。丸のタップは常に +1、右スワイプでスキップ。終わっていない単発は翌日以降にも出す。繰り返しは「終わらなければ翌日にも出す」がオンのものだけ 7 日まで出し、それより古いものは節の下に「ほか N 回（7 日より前）」
    - 並び（終わっていない → 終わった）は再描画までは変えない: 押した直後は丸・回数・薄さだけ変わり、行の位置は変えない。並びを組み直すのは、日を移る・予定タブを開き直す・読み直したときだけ（本人決定 2026-10-14）
    - 編集画面: 「時刻を決める」（オフで開始・終了が消える。新規の既定はオン）、「目標の回数」（− ＋、1〜99、既定 1。時刻の有無に依らず出す。ジム・睡眠の種類では出さない）、繰り返しのとき「終わらなければ翌日にも出す」（既定オフ。時刻なしだけ）。時刻なしでは種類の選択肢から睡眠を外す。時刻なしの単発は「日付」（繰り越し中は「10/10 から繰り越し中」と「日付を変える」）
    - 実績欄: 「回数 3/8」と − ＋（見ている日の時点の回数。− は見ている日以前の最新のタップを消す）・スキップ。過去日も回数の − ＋ とスキップは使える（予定は読むだけ）
    - 時刻つきの予定も目標の回数を持つ（既定 1 = 今の丸のまま。2 以上は「1/3」の丸＋進捗の輪で押すたびに +1）。時刻あり↔なしを切り替えても記録は残る
    - 一覧の丸は行の右端・大きめ（行のタップは編集画面。行の › は出さない）。時刻つきで目標 1 の回は、記録なしの丸を押すと実績の時刻のシート（予定の時刻が入った状態、保存で「やった」）。やった・スキップの丸を押すと記録なしに戻す（2026-10-14 本人指示。`day-cycle-walkthrough.md` 末尾）
    - 行の長押しでメニュー: 完了にする・完了を取り消す（目標 2 以上は 1回追加・1回取り消す）・スキップ・削除。中身は丸・スワイプ・回数の − と同じ操作だけで、使えない項目は出さない。完了した回（目標に届いた回）に完了にする／1回追加、記録のない回に取り消しは出さない（2026-10-14 本人指示。言葉は AI 既定。`day-cycle-walkthrough.md`「行の長押しのメニュー」）
    - 削除の出し分け（2026-10-15 本人決定・実装済み・未 commit）: 今日以降の一覧に出ている繰り越し中の繰り返しのやることは、その回だけ消せる（長押し・左スワイプ・開いた画面）。前日から続く時刻つきの行と、過去の日に出ている予定の行（繰り返しかどうかに関係なく）は消せないままで、長押しに灰色の「削除」と理由（「10/14 の予定です。前の日の予定は変えられません」「過去の日の予定は変えられません」）を出す。明日以降の一覧の、今日から続く行は「10/15 の予定です。前の日の予定はここからは消せません」（AI 既定）。予定外の実績は過去の日も消せる（`day-cycle-walkthrough.md`「消せる行と消せない行の区別」）
