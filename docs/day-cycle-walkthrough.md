### Google カレンダーの繰り返し予定の編集（調べた事実）
- 繰り返しの予定を編集・削除すると「この予定」「これ以降のすべての予定」「すべての予定」を選ぶ（Web・モバイル共通。Google カレンダー ヘルプ／How-To Geek）
  - この予定: その回だけ変わる。他の回はそのまま
  - これ以降: その回と以降が変わる。過去の回はそのまま
  - すべて: 過去も含めて全部変わる
- 出典: https://support.google.com/calendar/answer/37115?hl=en&co=GENIE.Platform%3DiOS 、 https://www.howtogeek.com/719013/how-to-add-edit-or-delete-recurring-events-in-google-calendar/
- **2026-09-30 本人補足**: 「過去日は変更できないから、Google カレンダーの『すべての予定を変える』は、Life Tracker では編集している日（編集できる時点で当日以降と確定している）以降のすべての予定を変えるということ」
  - → 繰り返しの予定の編集・削除の選択肢は **「この予定」「これ以降のすべての予定」の 2 つ**。過去の回はどの操作でも変わらない
  - → 「これ以降」は、元の繰り返しを前日で終わらせ、その日から新しい繰り返しを始める（繰り返しに開始日・終了日が要る）。その繰り返しにまだ過去の回がなければ、そのまま書き換える

### DB（migration `0006_template_version.sql`、本番適用は本人 OK 待ち）
```sql
-- 予定 (系列) は id だけを持つ。中身は世代に持つ
CREATE TABLE task_template_version (
  id             UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  template_id    UUID NOT NULL REFERENCES task_template (id) ON DELETE CASCADE,
  effective_from DATE NOT NULL,           -- この日から、次の世代の前日まで効く
  is_ended       BOOLEAN NOT NULL DEFAULT false,  -- true = この日以降は出ない (「これ以降を削除」)
  name           TEXT NOT NULL,
  category_id    UUID NOT NULL REFERENCES category (id) ON DELETE RESTRICT,
  start_minutes_from_midnight INT NOT NULL CHECK (0..1439),
  duration_minutes            INT NOT NULL CHECK (1..1440),
  rrule          TEXT,                    -- NULL = パターン (祝日) 経由でのみ出る
  UNIQUE (template_id, effective_from)
);
-- 祝日に出すか (パターンへの登録) も世代ごとに持つ。過去の祝日の表示を変えないため
CREATE TABLE pattern_version_membership (
  pattern_id UUID NOT NULL REFERENCES pattern (id) ON DELETE CASCADE,
  version_id UUID NOT NULL REFERENCES task_template_version (id) ON DELETE CASCADE,
  PRIMARY KEY (pattern_id, version_id)
);
-- 既存 2 件を第 1 世代 (effective_from = 2026-04-26、v2 の DB を作った日) に移し、
-- pattern_template_membership を移してから削除、task_template の中身の列を削除
```
- `task_template_exdate`（その日だけ消す）と `scheduled_task.template_id`（その日だけ変えた回）は系列の id を指したまま。世代が変わっても付け替え不要

### 組み立て

    OR (status = 'skipped' AND start_at IS NULL AND end_at IS NULL)),

- **実績欄（睡眠以外）**: 「記録なし／やった／スキップ」の segmented。やったのときだけ開始・終了。ツールバーの「保存」で実績と予定の変更をまとめて保存（実績を先に書き、失敗なら止める。予定の確認ダイアログ（この予定／これ以降）はその後）。過去日は予定の欄を読むだけの一覧（名前・種類・時刻・繰り返し）にし、削除ボタンは出さない
- **実績時刻の解釈**（レビュー §3-2）: 回の実績の開始は予定の開始の ±12 時間で最も近い時刻、終了は開始より後で最初のその時刻。footer に開始の日が回の日と違えば日付（「9/30(水) 0:30〜7:00 · 6時間30分」）、終了が翌日なら「（翌日）」
