### 級の計算（AI 既定・本人決定は【】・レビュー A-1〜A-5・A-7・A-8・A-16 反映）
- 計算順序は **セット → 種目 → 部位** の 1 本: 各セットに「そのセットの日以前で最新の体重」（無ければ最新の記録）を当てて級の値を出す → 種目 = セットの最大 → 部位 = 種目の平均【本人 Q4】。W（ウォームアップ）は除外（INV-4 と同じ）、アーカイブ済み種目（exercisesById に無い）は週分析と同じく除外。タップシートの「使った記録」は最大を出したセットとその日の体重
- セットの値: weight_reps = 推定 1RM（Epley）／reps_only = 回数／duration = 秒。自重の weight_reps（チンニング・チンアップ・ディップス胸/三頭。equipment = bodyweight かつ weight_reps の 4 件）は weight NULL を 0（加重なし）とみなし、加重 0 → 回数の表、加重あり → (体重＋加重)×Epley − 体重 → 加重の表（added_weight_kg）。混在はセット単位の max で解ける。既存の e1RM 指標（加重 0 → 0kg）は変えない
- 対応の規則: 種目の metric_kind と表の unit が一致しない対応は**基準なし**。バックキック（マシン）・マウンテンクライマー・ロシアンツイストの 3 件は 10/7 に対応表で none に落とした（10/8 以降は換算の対象）。読み込み時のテストで検出する
- 基準: 体重の表（性別別）。隣り合う体重行の間は線形補間、**範囲外（男 50〜140・女 40〜120kg）は端の行をそのまま**（外挿しない）。読み込み時に「昇順・5kg 刻み・5 値」を検証し、崩れた種目は基準なしに落とす（App.init で落とさない）。年齢の表は使わない（20 代は体重の表との差がほぼ無い。将来の補正候補: 年齢行 ÷ 25〜40 歳行の比を掛ける）。生年月日は保存と表示のみ
